### Q1 HTML이란 무엇인가요?

#### **책을 읽기 전 혼자 답해보기**

HTML은 HyperTextMarkupLanguage의 줄임말이며, 웹페이지의 기본이 되는 뼈대를 구축하는데 사용되는 언어이다. HTML이 프로그래밍 언어인가? 라고 하면 그렇지 않다 프로그래밍 언어라고 하면 함수를 작성할 수 있어야하고 그 함수를 동작시키는 등의 기능이 필요하다. 하지만 마크업 언어인 HTML 화면의 뼈대를 잡을 순 있지만 HTML 언어만으로 함수를 작성하거나 동작시킬 수 없다. HTML은 많은 태그가 있지만(div, p, a 등) 그 중 시맨틱 태그라고 불리는 태그들이 있다. 이 태그들은 `<head>` `<footer>` `<section>` 등이 있으며 이 태그들을 통해 스크린 리더는 화면 레이아웃이 어떻게 구성되어있는지 파악할 수 있다. 사실 사람이 보기에 div 태그로만 화면 레이아웃을 구성해도 보기에는 시맨틱 태그들을 잘 구조화해서 한 것과 똑같아 보일 것이다. 하지만 스크린 리더 입장에서는 다르다. 스크린 리더는 HTML을 읽을 때 시맨틱 태그들을 통해서 지금 여기 영역히 화면의 head구나 footer구나 하고 알 수 있기 때문이다. 웹 접근성, SEO를 한 번쯤 다들 들어봤을 것이다. 이 웹 접근성과 SEO 최적화에 가장 기본이자 중요한 것이 시맨틱 태그들을 잘 활용해 구조화하는 것이다. 검색 엔진에 우리의 사이트가 잘 노출되려면 시맨틱 태그들로 구성이 되어있어야 스크린 리더가 사이트를 이해할 수 있고 이는 곳 검색 노출 상위에 노출시키기 쉽다는 뜻이기도 하다. 그렇기 때문에 홍보성을 가진 사이트이거나 공식 홈페이지 등 연관 검색어와 연결되어 노출하려면 SEO, GEO 등 웹 접근성에서도 신경을 많이 써야한다.  

#### **책 정리**

1989년 팀 버너스리가 전 세계 연구자가 정보를 쉽게 공유할 수 있도록 웹을 만들었다. 
당시에는 컴퓨터 시스템과 플랫폼마다 사용하는 문서 형식이 달라서 불편했고 이를 해결하기 위해 설계한 마크업 언어가 HTML이다. 수학 기호나, 음악 기호처럼 사용하는 언어가 달라도 보편적인 표기체계는 이해할 수 있듯이 플랫폼에 상관없이 모든 컴퓨터가 동일하게 읽을 수 있는 형식을 제공한 것이다. 
HTML이란 의미를 담은 정보의 뼈대로 단순히 콘텐츠를 표시하는 것을 넘어 정보에 구조와 의미를 부여한다.

하이퍼텍스트는 특정 단어나 문장에 링크를 부여해 다른 문서나 페이지로 즉시 이동할 수 있게 만든 텍스트를 말한다. 웹에서 링크를 클릭해 이동하는 모든 행위가 하이퍼텍스트의 원리를 이용하는 것이다. 하이퍼텍스트는 웹의 가장 큰 특징인 연결성을 구현하는 핵심 개념

마크업은 ‘표시하다’라는 의미로 문서의 구조와 의미를 태그라는 약속된 기호를 사용해 표시하는 방식이다. 예를 들어 글자를 굵게 만드는 스타일인 font-weight을 적용하는 것은 시각적인 효과만 줄 뿐이지만 strong태그를 사용하면 중요한 정보라는 의미 자체를 웹 브라우저에게 전달할 수 있다.

HTML의 구조: 태그, 요소, 속성
HTML 문서는 요소의 집합으로 이루어지며 요소는 태그로 표현된다. 
요소에 추가 정보나 기능을 부여할 때는 속성을 사용한다. 

```html
<a href="https://www.naver.com">네이버</a>
```

위 코드에서 요소는 `<a/>`이고 속성은 href이며 그 값은 "https://www.naver.com"이다. 

HTML의 역할: 정보 구조화와 의미 표시

HTML이 웹에서 담당하는 역할이 정보의 구조화이다.
여기서 더 중요한 핵심은 의미를 표시하는 것이다. 단순히 글자를 크거나 굵게 보이게 하는게 아닌 이것은 제목이다. 이것은 메뉴 항목이다처럼 각 요소의 역할과 의미를 태그로 알려준다. 

HTML의 진화: 시맨틱과 웹 접근성
초기HTML은 문서의 구조를 표현하는데 집중했다. 웹이 발전하면서 각 요소의 의미를 명확하게 전달하는 것이 중요해졌고 이 과정에서 시맨틱 HTML이라는 개념이 등장했다. 이를 실천하는 구체적인 방법이 시맨틱 태그이다. 시맨틱 태그는 태그 이름만으로도 해당 영역의 역할을 알 수 있게해준다. 그렇기 때문에 의미에 맞는 시맨틱 태그를 사용하면 검색 엔진이나 스크린 리더같은 기기도 웹 사이트의 구조를 정확이 이해할 수 있어 검색 엔진 최적화와 웹 접근성에 매우 중요한 요소이다.
현재 웹 표준인 HTML5는 이런 시맨틱 웹의 철학을 적극적으로 반영한다. 
`<head>`, `<footer>`, `<nav>`, `<article>`, `<section>` 등 다양한 시맨틱 태그를 추가해 문서 구조를 더 명확하게 표현할 수 있게 했으며 별도의 플러그인 없이 비디오, 오디오를 재생할 수 있는 `<video>`, `<audio>` 웹에서 그래픽을 직접 그릴 수 있는 `<canvas>` 등 여러 기능으 대거 도입되어 웹의 표현력은 높였다.

#### 모의 면접

Q1: 웹 개발에서 HTML, CSS, 자바스크립트의 역할은 무엇인가요? 건물 짓기에 비유하면 각각 어떤 부분에 해당할까요?

> HTML은 건물의 뼈대인 철근과 콘크리트, CSS는 창문과 문, 외벽, 엘리베이터, 내부 디자인, 자바스크립트는 실제로 엘리베이터, 문, 화제경보기가 동작하도록 하는 것이다.

Q2: HTML에서 시맨틱 태그를 사용하는 이유는 무엇인가요? 이것이 검색 엔진 최적화(SEO)와 웹 접근에 어떤 도움을 줄까요?

> HTML의 목적은 웹 페이지 내 정보를 구조화하는 것이다. 이때 단순히 div를 태그해서 레이아웃을 구성할수도, CSS로 글자를 굵게하거나 할 수 있다. 하지만 div는 head, section, footer, aside 등의 시맨틱 태그로 글자는 strong 태그로 사용하는 등 의미에 맞는 태그를 사용할 때 웹 브라우저와 스크린 리더가 웹 페이지의 구조를 정확히 이해할 수 있도록 해준다. 또한 이런 시맨틱 태그 활용과 메타데이터 설정은 웹 접근성과 검색엔진최적화에도 유리하다. 한 줄로 정리하자면 웹 브라우저가 내 사이트의 구조를 정확히 이해할 수 있게할 때 웹 접근성, 검색엔진최적화에 용이하고 이를 위해서 시맨틱 태그가 필요하다.
